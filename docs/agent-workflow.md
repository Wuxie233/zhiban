# 知伴四阶段 LLM-Agent 工作流设计

知伴将“从个人复习资料到持续刷题陪伴”拆解为四个可跨学科复用的 Agent 阶段，所有阶段均共享用户的原始学习资料与结构化状态，不依赖特定学科硬编码规则。

## 阶段一：资料整理与范围提炼（Extractor）

- **输入**：用户粘贴的笔记或从 PDF / PPTX / DOCX 解析出的文本（截断至前 10,000 字符）。
- **任务**：识别所属课程与章节主题（`subjectTitle`），抽取 3～6 个彼此清晰的核心知识点（`name`、`desc`）。
- **输出约束**：严格 JSON，供学习者勾选本次练习范围。

## 阶段二：可溯源出题与依据核查（Quiz Generator）

- **输入**：原始资料 + 用户勾选的知识点 + 题量（3 题或 5 题）+ 可选错题薄弱点列表（用于变式再练）。
- **任务**：
  1. 围绕选定知识点命制四选一练习题，并产出分步解析（`steps`）。
  2. 为每道题匹配资料中的原文依据短句（`quote`，不超过 45 字）。
  3. 自我核查诚实度：若用户资料仅给出概念而题目需要一定学科常识推导，则在 `caution` 字段主动标明提醒；资料覆盖充分时置为 `null`。
  4. 在“针对薄弱点再练”模式下，刻意避开原题题干，转换题型视角与干扰项设计全新变式题。

## 阶段三：错题诊断与持久化记忆（Tracker）

- **数据层**：使用 SQLite 维护两张轻量表：
  - `kp_stats`：累计每个知识点的做题总数与正确数，计算实时掌握度百分比。
  - `wrong_book`：记录答错题目、用户当时误选选项、正确答案、原文依据与分步解析，支持标记“已掌握”后移出待练列表。

## 阶段四：苏格拉底式家教追问（Tutor）

- **输入**：原始资料摘要 + 当前错题题干与选项 + 用户误选项 + 历史追问轮次 + 最新疑问。
- **任务**：结合资料和用户具体的错误选项直接点破卡点，在 220 字以内用通俗步骤讲清原因，保持耐心且不空泛夸赞。
